COREY is a browser-based IFC review app built with Next.js, React, That Open,
Three.js, and web-ifc. The default workflow is local-first: users open IFC files
from disk and review them in the browser.

The repository is backend-ready for self-hosted deployments. The optional backend
stores model bytes in S3-compatible storage, metadata and persisted review data in
Postgres, and exposes API routes from the same Next.js app.

## Current Scope

- Local IFC upload
- 3D model rendering with That Open
- Selection and property inspection
- Spatial and model tree browsing
- Hide, isolate, and show-all visibility flows
- Section plane and length measurement tools
- Validation clauses, reports, and data-table workflows
- Optional self-hosted storage and compute routes
