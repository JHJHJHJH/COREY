---
title: Runtime Assets
description: How copied That Open and web-ifc runtime assets are managed.
---

The viewer depends on runtime assets copied into `public/`.

```text
public/workers/thatopen-fragments-worker.mjs
public/wasm/web-ifc.wasm
public/wasm/web-ifc-mt.wasm
```

These files are copied from installed dependencies and must stay aligned with
`@thatopen/fragments` and `web-ifc`.

## Refresh Assets

After upgrading the That Open or web-ifc packages, refresh the copied assets from
`node_modules`:

```bash
cp node_modules/@thatopen/fragments/dist/Worker/worker.mjs public/workers/thatopen-fragments-worker.mjs
cp node_modules/web-ifc/web-ifc.wasm public/wasm/web-ifc.wasm
cp node_modules/web-ifc/web-ifc-mt.wasm public/wasm/web-ifc-mt.wasm
pnpm check:assets
```

`pnpm check:assets` compares SHA-256 hashes between the copied runtime files and
their installed package sources.

## Sample Models

No sample IFC model is bundled by default. IFC files committed under
`public/resources` must have explicit redistribution rights and provenance.
