COREY helps project teams check IFC building models before submission. It was
built for CORENET X workflows, where models need to carry more complete BIM data
than many teams are used to providing.

The idea is simple:

1. Open an IFC model.
2. Validate the data against pre-configured checking clauses.
3. Export the model data to Excel.
4. Batch edit missing or incorrect values.
5. Import the Excel file back into COREY and validate again.

COREY keeps the review visual. You can see the model in 3D, click problem
elements, inspect their data, and fix repeated issues using familiar spreadsheet
workflows.

## The problem it solves

CORENET X raises the amount of BIM data that must be present in an IFC model.
Before submission, teams need to confirm that required information is present,
correct, and consistently filled in across many elements.

Checking that manually is slow. Reviewing a spreadsheet alone makes it hard to
see where an issue is in the actual model. COREY brings both sides together:
visual model review for understanding problems, and Excel import/export for fast
bulk correction.

## What makes it easy to adopt

- **Runs in your browser.** Nothing to install for everyday use.
- **Private by default.** Your files are read on your own machine and aren't
  uploaded anywhere, unless your team sets up the optional shared backend.
- **Works with Excel.** Export, edit, re-import, and validate again.
- **No BIM authoring tool required.** COREY is for reviewing and correcting model
  data, not modelling geometry.
